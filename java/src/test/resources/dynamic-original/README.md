# Original compound dynamic fixture

Generation uses the existing app dynamic-template generator: U+E522 followed by U+E520, font size 256, common baseline, tracking 0, cropped to observed ink and resized to height 64 with Lanczos. The test resizes the whole compound to height 28, preserving proportions.
