# Version subtitles

A nearby printed version subtitle remains part of the opening work title even
when the import name contains only the main heading. A literal subtitle already
owned by the title is excluded from unresolved contributor credits. Known names
and explicit review evidence prevent subtitle ownership.

For a damaged subtitle, bounded geometry and a version-shaped suffix nominate a
source row for rereading. A nomination does not supply letters. Acceptance uses
a complete 12-view grid from each of two readers: at least three complete literal
English captions over two modes and two strong scales, plus at least nine strong
medium readings agreeing on the type and differing by no more than one glyph.
Competing complete captions remain unresolved. Printed version numbers must
match the source and supporting readings. Only the source-bound row changes;
the detector then replays all pages and preserves contributor roles and unrelated
review evidence.

The regression uses original fictional headings and synthetic readings under
Apache-2.0. It contains no score scans, private library data, model weights or
device logs. Android PDF rendering, model-asset loading and full-library accuracy
require separate application verification; these synthetic tests do not prove them.
