# Beam shafts on shaded paper

A faint shaft could disappear where the paper became darker than an absolute
brightness floor, despite retaining the same local contrast and connected
geometry. The beam candidate path now has a separate relative-paper enclosure
predicate. Existing shared enclosure predicates and the caret/hairpin laws stay
unchanged.

The new path still requires bilateral paper at least 30 intensity levels above
the candidate, a bounded narrow section, the existing literal connected prefix,
authenticated head ownership, rival checks, and the full beam-strip and terminal
contact proofs. A literal section is a proposal, never an ownership certificate.
When both original absolute-brightness banks exist, their section remains
authoritative, including its geometric refusals. Relative banks are considered
only when at least one absolute bank is missing.

The new enclosure prepays `16 * radius + 56` abstract work units from the same
existing allowance, covering its extra bookkeeping. It performs at most
`6 * radius + 2` source-plane loads and allocates no arrays. This is a bounded
source-probe accounting model, not a CPU instruction or elapsed-time claim.
No pool or search cap is raised; funding refusals retain the existing caller
behavior.

Original caller regressions keep a connected shaft under the same nonclipping
exposure shift in both stem directions, and reject missing or disconnected
shafts. Preference and refusal controls cover absolute-bank acceptance and
rejection, weak contrast, broad bands, gradients, unilateral paper, source
immutability, exact funding and insufficient funding. The focused app and
standalone suites each pass 56 tests; five Python cache/wire tests also pass.
The legacy photometric comparator retains all 24,576 tested outcomes.

A fresh private five-page native comparison restores three complete beam groups.
All previously supported native edges, columns and detached flags are retained;
some shaft geometry expands. All notes, rests, written rhythms, keys, dynamics,
expressions and clock fields remain unchanged. Partial column or edge gains are
not counted as complete group repairs. Private score material is not published.

Recognition revision 122 invalidates derived caches across the matching source
contracts. Guide299, audio101, model weights and serialized layouts are
unchanged. Cumulative application/Hub/worker packaging, installed playback and
deployment remain separate completion gates.
