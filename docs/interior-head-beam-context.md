# Unowned interior heads cannot disappear from beam context

Physical grouping sorted only the shaft columns it could authenticate. If a
filled head between two columns had no uniquely proved shaft, its column was
missing from that list. A long raw strip could then incorrectly join the outer
columns and skip the intervening note.

The Source producer now retains its actual full authenticated head roster as
competing context across each proposed pair. A same-measure, same-physical-lane
head between the shaft bounds with no unique shaft vetoes that pair. This is
negative context only: it invents no shaft, pitch, voice, beam membership, or
Source owner. A head with an independently proved opposite-direction shaft
remains distinct voice context; an unproved blank/model-only head cannot veto.
Both strict and extended geometry passes use the same veto. Existing callers'
default pair contract allows their old paths unchanged.

The complete roster scan is prepaid against Source's existing128M logical-work
allowance before traversal. Existing whole-capture refusal on exhaustion remains;
no shaft, geometry or flag cap increases. There are no record/model/dependency
changes, and both changed files are already selected by the desktop worker.

One JUnit method runs96 original whole-Source assertions over three ink levels,
including absent/disconnected/ambiguous middle shafts, complete three-column
beams, independently owned opposite voices, model-only proposals, duplicate
unknowns, input immutability and refusal to fabricate isolated flags. The same
original test fails semantically on the old source without a compatibility
adapter. Existing raw/finite/Source/rival/resource controls remain unchanged.
These are original Apache-2.0 fields; no commercial pixels or private data ship.

Private saved-scalar all-five Source qualification removes three independently
audited false connections. Every correct audited edge and previously exact group,
all head/shaft facts, note origins and isolated-flag facts remain. This is three
false edge repairs, not three additional complete-group repairs. The scope uses
historical note/measure/staff scalars and original raw inputs; it does not restore
unavailable producer clocks or qualify a fresh model/full native pipeline. Matched
cumulative app/Hub-worker packaging remains deferred during the active audit.
