# Owned Current rest clocks

CurrentRestAudioContext is a pure Java source API for the actual owned full-Current score domain. It does not load a State file, run a recognizer, reclassify Original data or render audio. Prepare it from the exact full Current model and its declared literal Current rest clock rows. Never substitute SCP.original, an already selected arrangement, a note/audio index namespace or equal-valued records.

prepare(current,rows,nominal,boundary) first prepays the bounded fullCurrent target scan, validates raw literal rows, resolves/validates the effective exact frame, and binds existing Current target evidence before selection. Empty rows return null for the existing legacy route. Prepared has no public constructor, so admission cannot be replaced with an invented ready context. Unsupported/ambiguous dependent marks refuse explicitly.

The consumer's actual fullCurrent iteration must emit literal rest owners and expression occurrence owners. Selection carries that ordered port plus the selected score and original prepared source reference. project validates cardinality, range, uniqueness, known-index record agreement, frame agreement and exact source context. Record equality checks a supplied ordinal; it never discovers membership by equality. Local marks disappear when their actual rest is omitted; genuine SCORE tempo events retain their old global policy. The original test caller shows literal owner iteration and exercises both cases.

The projected score's rest events have actual musical anchors and can be consumed by existing ScoreExpressivePerformance and ScoreNavigationPerformance using Prepared.frame(). No numeric tempo is guessed from unrecognized character text, and no rest becomes a Sound/note. NOTE Sound clocks and held-sound mappings remain the actual caller's independent domain; do not invent or clip a NOTE clock to make a REST test pass. The exact-boundary standalone test uses an explicitly rest-only performed selection. The app-side279 tests additionally qualify the real reader/conversion/RenderSpec/performance/cache caller path.

CurrentRestWritten supplies immutable declared Placement values and validation against the literal fullCurrent rest record. Persistence adapters must implement the full current-rest-own-v1 record layout: State3 requires current_rest_written_format equal to that string and current_rest_written as an array. Each row has exactly rest_index,onset_bits,duration_bits, all strings. rest_index is canonical nonnegative decimal without leading zeros, at most6 digits; bit fields are exactly16 lowercase hexadecimal digits representing raw IEEE binary64. Onset is finite nonnegative (including negative zero), duration finite positive, row owner unique/in-range, literal kind only, duration raw bits equal the actual Current rest record. Full consuming interval/frame admission is additional. V1/V2 reject presence of these fields rather than accept and drop them; unknown formats, future versions, precision-altered version tokens, malformed/duplicate fields and unsupported rows refuse. Shared Fields/StateVersion helpers preserve the scalar grammar but are not a blanket State3 loader. The actual app/desktop retained reader remains a separate reviewed adapter.

This addition does not change EXP1/CLI format acceptance or advertise a packaged worker capability. Existing source APIs stay compatible. Legacy ScoreMeterMap factories retain float anchor semantics; only explicit exact mode uses retained binary64 spans. App-only selection modes, RenderSpec, recordings preferences and app cache identity are not copied into this standalone module. Original procedural tests exercise real expressive/navigation consumers and deterministic actual result fields; they do not claim a new public recording-cache service.

All code/test data is original Apache-2.0 source. No commercial score, model, phone capture, binary dependency or app history is included. run_source_tests.py compiles the standalone Java sources plus these overlays and17 original procedural JUnit cases using only JDK/JUnit/Hamcrest; no app, SDK, Gson, engine or package build.
