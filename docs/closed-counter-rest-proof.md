# Complete-counter non-rest proof

A pale portion of a closed bowl with a left descender can disappear from the
ordinary dark projection, leaving a fragment that resembles an eighth rest.
The existing lowered-voice eighth family now has an optional complete-source
proof that excludes this non-rest shape. Ordinary and quarter-rest rules are
unchanged.

Producer-issued head origins authenticate the original gray plane and its
registered photometric or rectified views. The proof requires one complete
finite source component owning every classified proposal pixel, one enclosed
paper counter, connected monotone banks, a continuous left spine and a finite
left-only tail. It refuses boundary contact, foreign ink, known head ownership
and the existing positive ledger evidence. It never replaces source pixels or
promotes a bounding box, label or image hash into ownership.

Accepted records stay in the legacy working lists throughout every scan,
duplicate check and deferred component read. Completed proofs mark exact event
identities; explicit producer mapping carries those marks to actual mapped
events and separate dot aliases. Only at the top-level rest-detector return,
before rhythm and clock inference, does the transaction remove those exact
records. Equal-valued unrelated records remain. This preserves legacy fallback
scheduling, including widened and restored component domains.

The separate invocation allowance is max(2,000,000, twice the input pixel count)
work units and 1,000,000 cumulative allocation bytes, with optional refusal above
20,000,000 pixels. Nested views share it. Traversals, origin checks, mark nodes,
identity lookups and output copies are paid. Any feature funding failure returns
the whole unchanged legacy detection. No existing limit is raised.

Thirty original and resource controls plus 68 retained rest tests pass in both
the app and standalone core. Controls include connected genuine rests, source
identity, exact funding boundaries, deferred scheduling, equal-valued records,
mapped aliases and late refusal. A fresh private five-page native run removes
one false rest and clears its exact physical owner's following-rest attachment;
the rest count changes accordingly. All 23 genuine source-rest controls, 212
physical beam groups, 358 previously supported edge masks, and every other final
field remain unchanged. Private score images and inputs are not distributed.

The source and native gates do not establish installed-app playback or matching
Hub/worker deployment. Models, weights and serialized layouts are unchanged.
