# Tilted staff binding uses the physical horizontal baseline

The local five-rule frame measured the vertical displacement between its two
sampled flanks against vertical staff spacing. Two distant flanks of a mildly
tilted staff could therefore fail even when all five actual rules fit. The check
now divides displacement by their actual horizontal separation, using the same
maximum slope as the retained legacy binding. The existing five-rule evidence,
uniqueness, gap, fit, phase, pitch and exact source/frame identity checks remain.

An original continuous affine raster regression covers four spacings, both tilt
directions and two raster phases, plus missing rules, steep inputs, immutability
and exact/one-under operation allowances: 72 assertions. It fails on the prior
source. Retained beam tests qualify separately. No score pixels or personal data
are distributed, and no model, record layout or dependency changes are needed.

The private five-page saved-input comparison adds 33 page-two note bindings,
including 11 independently audited grouped owners with matching system identity.
The other 22 are explicitly not independently visually qualified. It loses no
old beam connection and completes no additional beam group. This is saved-scalar

next cumulative matched app/worker update must advance recognition beyond the
