# Whole-staff printed-slur fallback

Local strips can lose an otherwise complete faint staff when a short exterior
rail contaminates their coverage. The optional slur fallback measures the actual
full-width raster and requires one unique five-rule family under the existing
contrast, scale, phase and complete-five/no-sixth laws. It never selects the
nearest or strongest rival family.

Legacy slur capture finishes first. Supplemental capture uses only previously
failed staff slots and unbound owners; existing spans, deferred candidates and
opaque IDs remain unchanged. New IDs identify the supplemental acquisition
route. Default frame preparation for dynamics, tuplets and other consumers stays
on its prior path.

The source is bound by raster identity, dimensions, thread and digest. One
projection is cached per exact failed domain. Optional work, memory and capture
limits refuse the entire new set while retaining legacy results. The20M-pixel
optional capacity also refuses safely on larger inputs accepted by the prior
pipeline; it does not narrow their accepted domain.

This retains the existing broad frame and head-row tolerance. A gently warped
five-rule raster can satisfy that law; the result does not establish a new local
head-pitch, voice or written-clock certificate. Independent entry probes found
no false slur output from the challenged rule families. Deferred geometry stays
deferred until its ordinary ownership and timing contracts close.

Original tests cover complete faint rules, local exterior rails, full sixth
rules, missing rules, distinct returning curves, domain/source mutation,
resource refusal, legacy identity and larger-page preservation. Private source
reconciliation adds seven active spans and eleven deferred observations while
retaining every earlier record and all other same-entry fields. Later clock
context and final pipeline outputs require the separate actual native gate.
No source-score pixels, model changes or record-layout changes are included.
