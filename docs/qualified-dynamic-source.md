# Qualified dynamic OCR source identity

One OCR read can observe both a complete qualified dynamic phrase and its
strength child. Treating both observations as separate strengths can anchor the
whole phrase to an earlier attack and emit an extra dynamic point.

`SuddenDynamicSource` recognizes this alternative only from an actual OCR parent
with exactly one qualifier and one strength child. The original qualified child
must already exist, retain its text and bounds, and meet the detector's existing
ink admission. The helper removes the duplicate parent or identical child
observations without inventing a new word or changing strength interpretation.

Source raster identity, dimensions, digest and thread bind the acquisition.
Parent identity also includes the actual read crop and scale; boxes outside that
crop refuse normalization. Conflicting ownership or bounded-work exhaustion
returns the entire unchanged observation list. Integral counts bound raw scans.
Technique and expression acquisition retain the original qualifier evidence.

The shared helper and original procedural regression use namespace-only
executable adaptation. Android and native acquisition adapters supply the real
OCR hierarchy and crop frame. The standalone adapter retains its caller-owned
inference and existing OCR sequence, captures source identity before acquisition,
and normalizes after its existing glyph and supplemental passes. Its original
acquisition remains available for expression reconciliation. The native decoder
explicitly selects the helper; the Android wrapper is reviewed separately.
Python's exported-caption pairing has no raw OCR acquisition counterpart and
requires no semantic or wire change. Models, existing recognition thresholds,
resource allowances and record layouts remain unchanged.

Original tests cover parent/child alternatives, independent repeated markings,
different strengths, compound dynamics, ambiguous or missing hierarchy, sparse
ink, changed rasters, cross-thread use, coordinate frames, crop escapes and
atomic resource refusal. Private source qualification includes a full native
model/OCR page run: exactly the duplicate point changes, with final expressions,
timing and other page fields preserved. This is source validation; cumulative
packaging, emulator and matched app/worker deployment are separate gates.
