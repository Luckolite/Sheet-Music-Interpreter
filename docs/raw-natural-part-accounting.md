# Accounting for actual raw-natural parts

Raw-natural recovery previously reserved retention and classification for the
maximum possible number of eligible components before component production.
It now prepays the complete crop, flood, storage and returned-list production,
then prepays the unchanged whole-crop bound before each actual eligible part is
retained, classified or checked for a continuation beyond the crop. An unpaid
part refuses the optional path rather than skipping ahead to cheaper alternatives.

The actual analyze operation still shares64,000,000 charged work units and16MiB
charged allocation bytes across early and final phases. Exhaustion is sticky;
there is no reset or refund. No glyph threshold, key authority, candidate order,
predicate, cap, model or record layout changes. The accounting bounds describe
charged work/storage, not measured runtime or exact JVM heap use.

Six original controls exercise actual raw proof and complete analyze calls at
their measured exact work/byte budgets and one unit below each. Existing key
tests and saved-stage result parity qualify the change separately. Fixtures are
original procedural drawings; no commercial score, private library or recorded
result is included. Matched packaging remains deferred during the active goal.
