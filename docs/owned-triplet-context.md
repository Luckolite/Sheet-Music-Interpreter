# Physically owned in-staff triplets and contrast consensus

A numeral inside the staff could be rejected even when three real single-beam
heads and both connecting beam spans owned it. The alternative requires the
existing same-operation numeral ownership proof, no competing owner, and three
pitched, non-grace, same-voice heads with matching stem direction and one beam.
Literal rests and incomplete groups cannot supply that evidence.

Contrast recovery previously compared every outline with only its first accepted
outline. A truncated first outline could hide agreement between two later
thresholds. Recovery now retains the existing twelve observations and checks
distinct-threshold pairs within the existing quarter-gap bounds. Every original
successful return retains priority; the new result is returned only after the
original search would fail. No threshold, raster-query count or resource cap is
increased. Up to twelve retained glyph references and twelve integers support at
most sixty-six additional pair comparisons.

The ten new original generated tests exercise the full triplet helper: three-head
ownership, absent/split shafts or beams, competing staff declarations, literal
rests, absent/wrong digits, later-threshold consensus and repeated masks at one
threshold. They use procedural engraving and the existing SIL-OFL Bravura glyph;
no commercial score, library, captured model output or device log is included.
The focused suite contains 159 passing tests. This does not certify general
recognition accuracy or a complete model/page/export run.
